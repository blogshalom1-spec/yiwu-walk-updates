샬롬군의 이우 한바퀴 개인정보처리방침

운영자: 샬롬군 · 시행일: 2026년 11월 18일
문의: blogshalom1@gmail.com

이 앱은 중국 이우시장 방문을 위한 지도·상품 탐색과 개인 업체 기록 도구입니다. 회원가입과 개발자 운영 서버로의 기록 동기화가 없습니다.

기기에 저장하는 정보

사용자가 입력한 업체 번호·업종·메모·상담 내용, 선택하거나 촬영한 사진과 위챗 QR 이미지, 북마크·방문 기록·위치 기준점·검색 및 화면 설정을 앱의 기기 내 저장소에 보관합니다. 개발자는 이 기록을 자동 수집하거나 판매하지 않습니다. 광고 SDK 및 개발자용 사용 분석·오류 수집 SDK를 사용하지 않습니다.

위치

사용자가 허용한 경우 앱 사용 중 현재 위치를 기기에서 확인하여 가까운 매장 표시와 방문 기록에 사용합니다. 백그라운드 위치 권한은 요청하지 않습니다. 권한을 거부하거나 설정에서 철회할 수 있고 지도에서 기준점을 직접 정할 수 있습니다. 실내 GPS와 지도 좌표에는 오차가 있을 수 있습니다.

사진·카메라·음성

사진은 Android 사진/파일 선택기로 선택한 파일만 가져오거나 기기의 카메라 앱으로 촬영합니다. 전체 사진 보관함 권한은 요청하지 않습니다. 음성 입력은 사용자가 시작하는 기기의 음성 인식 서비스에 맡깁니다. 해당 서비스는 설정과 제공자에 따라 음성을 서버로 전송할 수 있습니다. 시작 전에 안내하며, 앱은 반환된 원문 텍스트와 사용자가 확인한 정리 결과를 보관하고 음성 녹음 파일을 저장하지 않습니다. 음성 서비스를 사용하지 않고 직접 입력할 수 있습니다.

온라인 지도와 외부 서비스

외부 도보 지도는 사용자가 선택한 출구와 목적지의 좌표·이름을 고덕지도(Amap)에 전달하여 앱 안 웹 화면으로 엽니다. 이 좌표는 선택한 출구·식당 위치이며 GPS 현재 위치를 자동 전달하지 않습니다. 지도 제공자는 인터넷 연결 과정에서 IP 주소, 브라우저 정보와 자체 쿠키 등을 처리할 수 있습니다. 해당 화면에는 개인 기록·사진에 접근하는 앱 인터페이스가 없습니다. 지도 화면의 위치 요청은 허용하지 않습니다. 외부 자료 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다. 앱 내 기본 지도와 검색·기록은 오프라인으로 사용할 수 있습니다.

Google Play 배포판은 Google Play를 통해 업데이트합니다. 직접 설치 시험판은 GitHub의 공개 업데이트 정보를 확인하며, 이때 GitHub에 접속 정보가 전달될 수 있지만 개인 기록·사진은 전송하지 않습니다. Google Play, 기기의 음성 서비스, Amap 및 외부 사이트의 자체 정보 처리는 각 제공자의 정책을 따릅니다.

백업·내보내기

사용자가 선택한 폴더 또는 문서 제공자에 사진 포함 백업과 업체 자료를 내보낼 수 있습니다. 클라우드 저장 위치를 선택하면 해당 제공자에게 파일이 전달됩니다. 백업은 암호화된 금고가 아니므로 타인에게 공유할 때 사진·QR·연락처가 포함되는지 확인하세요. 자동 클라우드 백업과 기기 간 자동 동기화는 제공하지 않습니다.

보관·삭제

자료는 사용자가 기기에서 보관하는 동안 유지됩니다. 업체 삭제는 휴지통으로 이동하며 자동 영구 삭제되지 않습니다. 앱의 전체 로컬 정보를 없애려면 Android 설정에서 이 앱의 저장공간을 삭제하거나 앱을 제거할 수 있습니다. 이 작업은 복구할 수 없으므로 필요한 자료를 먼저 백업하세요. 앱 밖으로 내보낸 파일은 해당 저장 위치에서 별도로 삭제해야 합니다. 개발자 서버에는 해당 기록이 없으므로 개발자가 원격으로 복원하거나 삭제할 수 없습니다.

연락·변경 안내

문의 이메일을 보내면 회신에 필요한 이메일 주소와 문의 내용을 이메일 서비스에서 처리합니다. 민감한 개인 기록이나 다른 사람의 사진을 불필요하게 보내지 마세요. 개인정보 관련 문의와 삭제 요청은 위 이메일로 연락할 수 있습니다. 처리 방식이 바뀌면 이 페이지와 앱 안의 안내를 갱신합니다.
